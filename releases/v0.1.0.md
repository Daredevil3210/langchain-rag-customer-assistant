# v0.1.0 - 客服知识库 RAG 案例

## 内容

- 发布 Atguigu Assistant 客服知识库 Notebook、示例知识文本和完整依赖清单。
- 提供 README、MIT LICENSE、环境变量占位模板和 Git 忽略规则。
- 演示文档加载与切分、嵌入向量生成、Milvus 入库和检索，以及基于上下文的 Agent 回答生成。

## 整理

- 修正 `generate_answer()` 的检索参数，传入用户问题而非 Python `str` 类型。
- 清除 Notebook 的历史输出和执行元数据。
- 将完整依赖清单转为 UTF-8，依赖版本保持不变。
- 不包含 `.env`、真实凭据、上传操作单、其他章节、IDE 配置、缓存或解析临时文件。

## 运行与验证

- 需要 Python 3.13、可连接的 Milvus，以及本地配置的硅基流动和 CLOSEAI API 凭据。
- 默认初始化步骤会删除并重建 `rag_tutorial` 数据库中的 `docs` 集合，请使用专用练习数据。
- Notebook 格式、代码语法、素材引用和敏感信息检查；通过模拟依赖验证问题到检索、上下文到生成的传递。
- 未执行真实数据库或在线模型的端到端测试，也未重新安装完整依赖清单。
